## 二、中国药科大学

### 药学院（四系一中心）

1. 药物化学系
2. 药物制剂系
3. 药物分析系
4. 药理系
5. 国家药学实验教学中心

### 生命科学与技术学院 / 生物药物学院

以研究方向团队运作，覆盖疾病生物学、神经生物学、计算生物学、分子生物学、合成生物学、生物物理学、微生物与免疫，以及抗体工程与细胞治疗、基因治疗与核酸药物、微生物来源药物等方向。

### 中药学院

以学科方向运作：中药化学、中药分析学、中药资源学、中药制药、中药生命组学、生药学等。

### 基础医学与临床药学学院

以学科方向运作：药理学、临床药学、药物代谢动力学、基础医学。

### 工学院（三系一中心）

1. 制药与环境工程系
2. 食品营养与安全系
3. 生物医学工程与诊断药学系
4. GMP 实训中心

### 化学学院（2026 年 7 月新设）

以学科方向运作：药物化学、药物分析学、农业药学。

### 人工智能学院（2026 年 7 月新设）

以学科方向运作：医药大数据与人工智能、人工智能药学、生物统计。

### 多靶标天然药物全国重点实验室（5 个研究中心）

1. 天然药物与现代中药研究中心
2. 药物代谢动力学及成药性研究中心
3. 高端药物制剂与材料研究中心
4. 新药研究中心
5. 新药筛选与药效评价中心

### 国际医药商学院

以学科方向运作：社会与管理药学、药物经济学。

## 三、南京农业大学

### 生命科学学院（4 个学系）

1. 植物生物学系
2. 微生物学系
3. 生物化学与分子生物学系
4. 动物生物学系

对应学科点：植物学、动物学、微生物学、生物化学与分子生物学、生物技术、发育生物学、细胞生物学。

### 动物医学院

以学科方向运作：基础兽医学、预防兽医学、临床兽医学、动物药学（含兽医生物制品方向）。

### 食品科技学院

以学科方向运作：食品科学与工程（关联学科）。

---

## 四、东南大学

### 生物科学与医学工程学院（4 个系）

1. 生物医学工程系
2. 生物信息学系
3. 脑与学习科学系
4. 智能医学工程系

对应方向：神经信息工程、医学图像与医学电子学、生物医学纳米技术、生物医学材料、器官芯片。

### 生命科学与技术学院

以课题组运作，覆盖神经发育与功能的调控机制、干细胞的基础与应用、发育疾病的遗传调控与临床转化等方向。

### 医学院

以临床学科教研室为教学单元，覆盖基础医学、临床医学各学科。

### 公共卫生学院

以学科方向运作：流行病与卫生统计学、劳动卫生与环境卫生学、营养与食品卫生学、卫生毒理学。

### 生命科学与医学部

**生命科学学院（4 个系）**
