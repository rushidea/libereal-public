## 五、使用建议

1. 征稿推文发布后，优先在 A 级学系的班级群、课题组群转发（南医大基础医学院、药学院，药大药学院、生技学院，中科大生科院）。
2. 技术类选题与作者招募联动：写"免疫染色背景脏"这类文章时，同步从南医大免疫学系、病理学系招募作者。
3. 采购类内容面向各校公共平台负责人定向约稿，与其补货、经费周期（学期初、经费到账季）配合。
4. 生活类稿源充足，学生署名按文末动态生成规则取新 id，从不同学校学系轮换取材，避免同一学校连续出现、同一昵称重复使用。

## 六、学生池动态生成规则（2026-08-16 新增）

学生声音的署名不再使用固定人设（旧池：栗子、噜噜、阿白、士多啤梨酱、小苏打），改为每次投稿动态生成新的身份 id。固定人设仅作为语气风格参考，不再直接署名。

### 生成公式

每次投稿生成：`{入学年级}级{来源专业}-{昵称}`，三个字段规则如下。

**年级**：按投稿人实际入学年份取后两位（如 2026 年入学硕士 = 26级）。生活类常用研一至研三（25级/24级/23级等），毕业季可向前调整。

**专业**：由投稿人来源学系映射，优先取学系名或对应学科名：

| 来源学系 | 专业字段 |
|----------|----------|
| 南医大免疫学系 | 免疫学 |
| 南医大病原生物学系 | 病原生物学 |
| 南医大细胞生物学系 / 生技方向 | 细胞生物学 |
| 南医大生物化学与分子生物学系 | 生物化学 |
| 南医大药理学系 | 药理学 |
| 南医大公共卫生学院各系 | 公共卫生 |
| 药大药物化学系 | 药物化学 |
| 药大药物分析系 | 药物分析 |
| 药大药剂系 / 制剂方向 | 药剂学 |
| 药大生技学院 | 生物技术 / 生物制药 |
| 药大中药学院 | 中药学 |
| 南农微生物学系 | 微生物学 |
| 南农动医院 | 兽医 / 动物药学 |

**昵称**：从词库随机抽取，每次取用后标记已使用，不再复用（与已发表文章去重：002-噜噜、006-栗子、009-小苏打、011-阿白 已占用，从词库剔除）。

### 使用约束

1. 每次投稿生成后，将「年级+专业-昵称」记入已用名单（可维护于本文档或运营台账），防止跨期重复。
2. 同一来源学系连续投稿时，专业字段相同但昵称必须不同；同一学校连续出现不超过两篇。
3. 动态生成只适用于学生声音；从业者声音（职能-称呼）按职能岗位取固定称呼，不动态化。
4. 语气风格仍按稿件类型选组（生活类可全风格混用，技术类优先踏实细节组与内敛冷幽默组）。
