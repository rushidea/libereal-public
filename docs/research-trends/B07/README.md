# B07：计算与组学测量的四个研究专题

本批次包含 H003、H004、H008 与 H009。成果仅用于后续研究简报与页面制作：不包含诊疗建议、产品推荐或未经原始研究支持的因果结论。

## 文件说明

- `sources.csv`：90 条已核对的专题—来源记录，对应 89 篇独立论文；其中 1 篇多组学综述因同时承担 H008 的技术框架和 H009 的空间接口说明而跨专题复用。H003 与 H009 各 23 条记录，H004 与 H008 各 22 条记录。
- `evidence_map.csv`：每个专题 5 个可写入研究简报的综合单元，并列出支持来源和不可外推边界。
- `topic_boundaries.csv`：专题的纳入范围、排除范围及前端表述原则。
- `cross_source_synthesis.csv`：跨来源审定后的核心结论、证据范围和表达边界。
- `argument_chains.csv`：代表性研究的起点、设计、结果和结论边界，用于解释综合判断如何形成。
- `methods.csv`：可用于前端方法卡的研究工具、输入、读出、质量控制和限制条件。
- `progress_milestones.csv`：按时间组织的主要进展，逐项记录研究问题、论证路径、结果、证据层级和外推边界。
- `applications_diseases.csv`：应用与疾病研究场景，记录样本语境、研究结果、证据阶段和不可外推范围。
- `public_content_priorities.csv`：Sol｜High 审定的进展主线、公开呈现优先级、排列顺序和外推边界。
- `public_brief_final_review.csv`：扩写后四份简报的论证强度、呈现优先级、跨专题边界和发布前终审状态。
- `public_brief_sections.csv`：四篇公开研究简报的完整栏目初稿，含论证链、结论和引用映射。
- `research_trends_b07_snapshot.json`：由终审成果生成的公开快照，位于研究资料库 `data/frontend/`，仅包含公开栏目、方法卡和题录。
- `public_brief_structure.csv`：四个公开研究简报的五栏信息层级与写作任务。
- `editorial_decisions.md`：跨专题去重、术语和引用规则。

## 核验原则

题录、期刊、出版日期和 DOI 均以 PubMed 原始记录核对。纳入来源以 2020–2026 年已发表的原始研究、基准比较、方法论文和高质量综述为主；预印本、与主题不直接相关的应用论文，以及出版日期晚于 2026-08-27 的记录不纳入正式来源表。

“模型预测”“跨样本关联”和“实验验证”分别记录。算法的分类、检索或整合结果只能支持其数据集、实验体系和评价指标内的判断；只有有针对性的扰动、正交测量或独立样本复现，才可支持相应的功能性表述。
