# LIBEREAL 服务号写作整改指南（反模板化）

> 制定日期：2026-08-09。针对 006-008 暴露的"行文风格一致、AI 味重"问题制定的长期写作规则。后续每篇文章生成后必须对照本指南自检。

## 一、开头禁止清单

| 禁止句式 | 原因 | 替代方案 |
|---------|------|---------|
| 「做 XX 这些年/这几年」 | 006、007、008 连续三篇同款开头 | 直接扔一个具体场景、反常现象或一次真实对话 |
| 「最大的问题是/最常见的是」 | 总结腔，像 FAQ 开场 | 从一个具体吐槽、自嘲或疑问切入 |
| 「很多同学/很多老师问我」 | 伪互动开头，AI 味重 | 以「上周」「昨天」「上星期三」开头讲一件具体的事 |

模板与改进对照：

- 模板：做 IHC 技术支持这些年，碰到最多的电话……
- 改进：上周三下午两点半，电话响了，对面是个崩溃的师姐——"片子又糊了，背景脏得跟泼了酱油一样。"

判断标准：去掉具体时间、具体人物、具体画面后开头是否还成立。还成立，说明开头还是空的，重写。

## 二、段落长度必须错落

每篇文章至少包含三种段落长度：

- 短段（1-3 行）：扔观点、吐槽、转折
- 中段（4-6 行）：正常展开
- 长段（7-10 行）：某一段彻底展开，允许「跑题」几句再拉回来

禁止：连续三段以上长度接近、结构相同。

## 三、语言「去 AI 味」措施

### 每篇至少一处「小瑕疵」（以下任选其一，刻意保留）

- 一个错别字或打错字
- 一句不通顺的口语碎句（「说实话那个封闭液吧，我觉得……」）
- 一个赘词重复（「就是……就是……」）
- 半句话没说完突然跳转

### 禁用模板化过渡

- 首先……其次……最后……
- 第一……第二……第三……
- 说白了 / 换句话说 / 翻译一下

### 允许的自然过渡

- 说到这，我突然想起……
- 其实这里有个很细的点……
- 不过这里有个坑，注意一下
- 顺带一提

### 句式要求

- 禁止连续三段长句，每隔一段至少一个短句或断句
- 段落开头避免全部用「我们/我」开头，换着来

### 强调词密度控制（2026-08-16 新增）

「最」字是重灾区，010/011 两篇共 15 处全部清除后文气明显更顺。规则：

- 禁止同句内「最A、但最B」并列最高级对仗（如「最常翻车、但最不被当回事的事」），改写为「翻车太常见了，可几乎没人把它当回事」
- 全文控制「最」字密度，以下替换是 010/011 实践过的现成方案：
  - 最值 → 才值
  - 最容易（翻车/犯的错/当正常放过）→ 容易 / 常常 / 老有人
  - 最稳定 → 更稳定（对比语境下语义更准）
  - 最省事 → 能省不少事
  - 最漂亮 → 数据漂亮
  - 嫌疑最大 → 嫌疑很大
  - 最笨的办法 → 挺笨的办法（保留自嘲语气）
  - 用最短的话 → 每篇用两三句话
  - 最好是近两年的 → 近两年的优先
  - 最后查 / 最后做 / 到最后 / 最后是 → 接着查 / 小样培养验证也得做 / 一直到 / 结果是
  - 最低配 → 整句重写或直接删
- 只有删除后会丢失语义核心（确实在描述唯一最高级）时才保留「最」，但两篇实践表明绝大多数可自然替换

## 四、人设声音矩阵（强制区分，核心）

「换名字不换声音」是 002-012 的主要失败点：所有文章共享同一骨架（场景开场 → 其实/说实话 → 三个 `# #` 小标题段落 → 你们…留言说说），跨人设共用「说真的 / 其实 / 说实话 / 我们组这些年」等标志性词，导致不同作者读起来一个味。必须从词汇、节奏、开场、钩子四个维度把人设拉开。

### 写前必做：人设声音简报（voice brief）

动笔前先填一份声音简报作为锚点，不写进文章，只用于自我约束。简报不齐不准写：

- 称谓 / 年级 / 专业：
- 一句话内核（这个人此时此刻是什么状态）：
- 专属口语词（3 个，必须不与其它人重复）：
- 禁用词（2 个，避免和同类或他人撞车）：
- 开场套路（场景 / 观点直入 / 自嘲 / 问句，择一）：
- 段落节奏（短碎跳脱 / 均衡 / 长句铺陈）：
- 收尾钩子类型（见第五节，按声音选）：

### 学生声（第一人称「我」，在读研究生视角）

| 撰稿人 | 专属口语词（示例） | 段落节奏 | 开场套路 | 禁用表达 |
|--------|------------------|---------|---------|---------|
| 活泼话多（传代侠/噜噜） | 我跟你说、真的、咱、欸、你懂的 | 长短跳跃，常插括号式碎句 | 具体场景 + 对话 | 过于成熟的总结腔、惜字如金的沉默 |
| 内敛冷幽默（阴性对照/阿白） | 大概、多半、估计、未必、也未必 | 短句为主，留白多 | 一个冷冷的观察/反常现象 | 感叹号堆砌、长篇大论 |
| 过来人感慨（栗子/老跑胶） | 那年、早些年、我读研时、说起来、记性 | 长句铺陈，带怀旧 | 回忆式场景 | 活泼俏皮、过分简短 |
| 菜鸟好奇（新手枪/刚复苏） | 第一次、原来、啊？、师姐说 | 短句多、惊叹多 | 问句 / 「刚进组那会儿」 | 装懂、老成 |
| 踏实细节（小苏打/量筒） | 具体说、精确到、按规格、其实 | 信息密集偏长 | 具体步骤/规格切入 | 浮夸、抒情 |

### 从业者声（第一人称「我」或「我们组」，资深视角）

| 撰稿人 | 专属口语词（示例） | 段落节奏 | 开场套路 | 禁用表达 |
|--------|------------------|---------|---------|---------|
| 试剂组-冰箱贴 | 常温还是 4 度、效期、批次、我记得清 | 均衡，平稳 | 「我这人记性不好，但瓶子记得清」 | 年轻化网络用语 |
| 售后-急救包 | 接到电话第一句、上个月有个客户、排查下来 | 案例式「现象→排查→结论」 | 救场式对话 | 教科书条目罗列 |
| 售后-陈工 | 直接给结论、测下来、说白了 | 技术直给，干脆 | 直接亮数据/案例 | 情绪化感慨 |
| 技术支持-对照组 | 这些年见的多了、关键在于、你注意 | 理性带冷幽默 | 方法论切入 | 情绪泛滥 |
| 技术支持-阿杰 | 说真的、遇到过、别慌 | 案例 + 原理 | 场景式求助转解答 | 空泛感慨 |
| 采购组-薅羊毛 | 这笔账算下来、这行干久了、囤不囤 | 算账式，干脆 | 「这行干久了」 | 学术腔 |

规则：
1. 不同人绝不允许共用标志性口语词；同类（如两位售后）必须用「专属口语词」「开场套路」明确区分。
2. 同一撰稿人连续出现时，后一篇必须改变句式结构，避免「同人同腔」。
3. 标志词密度：每人每篇的专属词出现 2-4 次即可，不要堆；其余用词回到中性，避免人人都挂一堆口头禅。

## 五、互动钩子多样化

### 全文禁用

- 留言说说
- 评论区聊聊
- 你 XX 吗？留言说说
- 有没有遇到过？欢迎留言
- 评论区见（006、008 连续使用过）

### 允许的钩子类型（每篇轮换）

| 类型 | 示例 |
|------|------|
| 自嘲式 | 「反正我现在都是直接重买，省得折腾。」 |
| 感慨式 | 「写到这有点感慨，实验室这些东西，有时候经验比说明书管用。」 |
| 求助式 | 「有没有师兄师姐知道更好的办法？教教我。」 |
| 吐槽式 | 「老板要是看到这段估计会翻白眼，算了，写完再说。」 |
| 一句话带过 | 「就这样。有问题随时问。」 |
| 场景式 | 「下次组会要是有人问起来，这段可以拿去应付。」 |

钩子必须贴合该篇撰稿人声音，弱化「留言」二字时以自然收尾代替。

## 六、成稿自检清单

1. 开头没有使用「这些年/这几年/最大问题」
2. 段落长度有三种以上变化
3. 至少一处口语碎句或轻微不通顺
4. 没有对称排比过渡（「首先……其次……」）
5. 结尾钩子没有使用「留言说说/评论区聊聊/评论区见」
6. 撰稿人语感与同人前篇有明显差异
7. 允许一到两个句子略显啰嗦或重复
8. 校对时只改事实错误，不把「瑕疵」改回工整
9. 涉及实验事故或操作细节的段落，事故物件必须能真实导致所述后果，且与前文规则逻辑自洽：规矩 → 物件 → 后果 须形成闭环。例如「一整批细胞直接废掉」须由培养基污染/打翻这类能直接影响细胞的物件引发，不能用「枪头盒打翻」这种只撒吸头、与细胞无关的场景凑因果。不随手抓一个「听起来像实验室」的物件填充事故叙事。
10. 解释「为什么」的因果句（尤其「是怕…」「因为…」「为了…」结构）必须物理/逻辑上说得通，且说清具体机制，不能用「一手印子」这类不知所云的占位短语凑字数。写完反问一句：这句话描述的动作真的会导致所说的后果吗？若答不上来就是魔幻文字，必须重写。

11. 标点必须用大陆规范：引号用弯引号""，不用直角引号「」（那是港澳台用法，大陆读者看着像乱码）；引用在引号内的问句、感叹句必须把 ？/！ 写进引号里面，不能让问号悬在引号外或漏写。生成后通读一遍，凡是带疑问语气的句子核对结尾标点。

12. 配图（封面与正文插图）的画面逻辑必须贴合实验室真实操作，禁止画出违反常识的场景：超净台 / 生物安全柜操作默认坐姿（坐凳子、上半身探入柜内），不得画成站着操作；无菌操作忌讳两人手在柜内接触，旁人只能站在柜外隔空指点，不得伸手进柜、不得手碰手；超净台前不得另放桌子。生成插图提示词时把「seated on a lab stool」「standing safely beside, not touching」等约束写进 prompt，生成后人工核对画面。

## 七、校对原则（重要）

校对（Peter）与编辑（Sea）只修正事实错误、错别字不影响阅读的部分。刻意保留的口语碎句、轻微不通顺、赘词重复一律不改，防止「越改越 AI」。
